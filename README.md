# RazorAI — AI-Powered Conversational Sales & Checkout Agent

RazorAI is an AI-powered shopping assistant that helps users discover products, compare options, find the cheapest and highest-rated products, and complete a simulated checkout.

## Features

-  Conversational shopping assistant
-  Product discovery based on user requirements
-  Budget-based product recommendations
-  Highest-rated product selection
-  Cheapest product identification
-  Buy Now and checkout flow
-  Demo order confirmation

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Razorpay Python SDK

## How It Works

1. User tells RazorAI what they want to buy.
2. RazorAI asks for their budget.
3. The system finds suitable products.
4. Users can compare products or choose the cheapest/highest-rated option.
5. Users click **Buy Now**.
6. RazorAI displays an order summary.
7. The user confirms the order.
8. A demo order confirmation is displayed.
